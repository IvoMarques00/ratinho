# identity/

## Purpose

Durable information about Ivo as the owner of this repository: preferences,
principles, working style, decision patterns, communication style, and
long-term objectives. This is the "who" that everything else in the PMA
serves.

## Contents

- `profile.md` — the single identity document, covering all of the above.
  Kept as one file at v0.1; split later only if it grows unwieldy.

## Ownership

Ivo, exclusively — this folder is never written to on someone else's behalf.

## Maintenance Rules

- Only durable information belongs here. If something might change within
  weeks, it's not identity — it's `strategy/` (active priorities) or
  `tasks/` (ephemeral).
- Update sparingly and deliberately; this isn't a journal.

## AI Usage Rules

Read `profile.md` for context on preferences and working style before
undertaking planning, research, or communication-heavy work. Never infer a
permanent preference from a single interaction and write it here — confirm
durability first (repeated pattern, or explicit statement of a lasting
preference).

## Relationships

`strategy/` translates identity-level long-term objectives into concrete
vision and roadmap items. `memory/preference-memory.md` is NOT a duplicate
of this folder — memory holds small pointers to recent/contextual
preference signals, while `identity/profile.md` holds the settled, durable
version.
