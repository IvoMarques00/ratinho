# New Project

## Trigger

Starting a new time-bound or ongoing initiative.

## Preconditions

A goal exists, even if not yet fully scoped.

## Steps

1. Establish the goal and check traceability to `strategy/`. — invokes
   [Planning](../skills/planning.md).
2. Create the project folder and README from
   [templates/project-template.md](../templates/project-template.md). —
   invokes [Documentation](../skills/documentation.md).
3. Link the new project to relevant `domains/` and `knowledge/`. — invokes
   [Knowledge Management](../skills/knowledge-management.md).
4. Break the goal into initial `tasks/` entries. — invokes
   [Project Organization](../skills/project-organization.md).
5. Add a one-line entry to `memory/project-memory.md`.

## Skills Referenced

- [Planning](../skills/planning.md)
- [Documentation](../skills/documentation.md)
- [Knowledge Management](../skills/knowledge-management.md)
- [Project Organization](../skills/project-organization.md)

## Outputs

A new `projects/<name>/README.md`, initial `tasks/` entries, and a
`memory/project-memory.md` entry.

## Filing

`projects/<name>/README.md`; `tasks/`; `memory/project-memory.md`.
