# Feature Development

## Trigger

A new feature is being added to a project's codebase.

## Preconditions

The project exists in `projects/`, and the feature's goal is clear.

## Steps

1. Confirm the feature traces to the project's goal / `strategy/`. —
   invokes [Planning](../skills/planning.md).
2. Implement the feature in the target codebase. — invokes
   [Software Development](../skills/software-development.md).
3. Capture any durable technical knowledge surfaced. — invokes
   [Knowledge Management](../skills/knowledge-management.md).
4. Update the project's status and tasks. — invokes
   [Project Organization](../skills/project-organization.md).

## Skills Referenced

- [Planning](../skills/planning.md)
- [Software Development](../skills/software-development.md)
- [Knowledge Management](../skills/knowledge-management.md)
- [Project Organization](../skills/project-organization.md)

## Outputs

A code change in the target codebase; updated `projects/` entry; any new
`knowledge/` notes.

## Filing

Target codebase (e.g. `apps/`, `packages/`); `projects/<name>/README.md`;
`knowledge/`.
