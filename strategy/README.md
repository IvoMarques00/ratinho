# strategy/

## Purpose

Bridges durable `identity/` objectives to concrete, changeable work in
`projects/` and `tasks/`. Holds vision, roadmap, active priorities, future
opportunities, and focus areas.

## Contents

- `vision.md` — long-term direction, changes rarely.
- `roadmap.md` — active priorities and focus areas, changes regularly.

## Ownership

Ivo.

## Maintenance Rules

- `vision.md` should be stable; if it's changing often, that's a sign it was
  actually roadmap-level content.
- `roadmap.md` is expected to change regularly — that's its job. Review it
  during `workflows/weekly-review.md` and `monthly-review.md`.

## AI Usage Rules

Before starting a new project or significant task, check this folder for
whether it connects to an existing priority, and set `related:` accordingly.
If nothing fits, say so explicitly rather than silently skipping the link.

## Relationships

`identity/profile.md` → `strategy/vision.md` → `strategy/roadmap.md` →
`projects/`/`tasks/` is the intended chain of traceability from durable
identity down to a specific piece of work.
